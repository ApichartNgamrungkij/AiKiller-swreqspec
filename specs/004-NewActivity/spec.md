# Feature : สร้างกิจกรรมใหม่ (Create Activity)
# Status: Draft v2
# Last Updated: 2026-10-04

## Goal

ตัวแทนองค์การนักศึกษาที่ได้รับสิทธิ์จาก Admin และมีกิจกรรมที่ผ่านการอนุมัติจากมหาวิทยาลัยแล้ว
สามารถบันทึกรายละเอียดกิจกรรมและช่องทางลงทะเบียนเข้าสู่ระบบ
เพื่อให้นักศึกษาสามารถค้นหาและเห็นกิจกรรมนั้นได้


## Scope

### In Scope

- ผู้จัดกิจกรรมเปิดหน้า "สร้างกิจกรรมใหม่"
- ผู้จัดกิจกรรมต้องยืนยันอีกครั้งก่อนบันทึกกิจกรรมใหม่จริง ๆ
- กรอกรายละเอียดกิจกรรม ได้แก่ ชื่อ ประเภทกิจกรรม วันเวลาที่จัด สถานที่ที่จัด จำนวนรับสมัคร และชั่วโมงจิตอาสาที่จะได้รับ
- มีข้อมูลวันเวลาแบบช่วงเวลาเดียวแต่สามารถมีหลายรอบภายในวันเดียวกัน เช่น เช้า/บ่าย
- แนบลิงก์ URL สำหรับใช้ลงทะเบียนกิจกรรม
- บันทึกกิจกรรมเข้าสู่ระบบ
- ตรวจสอบว่าข้อมูลที่จำเป็นถูกกรอกครบก่อนบันทึก
- เผยแพร่กิจกรรมให้นักศึกษาเห็นหลังบันทึกสำเร็จ
- ผู้จัดกิจกรรมสามารถแก้ไขกิจกรรมหลังจากสร้างแล้ว และระบบต้องบันทึกประวัติการแก้ไข (edit log)
- ผู้จัดกิจกรรมสามารถยกเลิกกิจกรรมได้ และระบบต้องแจ้งเตือนผู้ที่ลงทะเบียนว่ากิจกรรมถูกยกเลิก
- กิจกรรมต้องอยู่ในประเภทกิจกรรมที่มหาวิทยาลัยรับรอง


### Out Scope

- การขออนุมัติโครงการจากมหาวิทยาลัย
- การขออนุมัติงบประมาณ
- การขออนุมัติจำนวนชั่วโมงจิตอาสา
- การจัดการสิทธิ์ผู้จัดกิจกรรม
- การลงทะเบียนเข้าร่วมกิจกรรมของนักศึกษา
- การอนุมัติกิจกรรมซ้ำโดย Admin ก่อนเผยแพร่
  (ระบบพิจารณาว่ากิจกรรมที่ผ่านการอนุมัติจากมหาวิทยาลัยแล้วและมีสิทธิ์ใช้งานจาก Admin จึงสามารถเผยแพร่ได้ทันทีโดยไม่เริ่มกระบวนการอนุมัติซ้ำ)


## Constraints

- CON-ACT-01 ผู้จัดกิจกรรมต้องได้รับสิทธิ์ใช้งานจาก Admin แล้วก่อนสร้างกิจกรรม ตาม UC-08 Precondition

- DOM-ACT-01 กิจกรรมที่สร้างต้องเป็น 1 ใน 5 ประเภทที่มหาวิทยาลัยรับรอง ได้แก่ วิชาการ, กีฬา, ศิลปวัฒนธรรม, คุณธรรมจริยธรรม และบำเพ็ญประโยชน์

- DOM-ACT-02 ระบบต้องไม่เข้าไปแทนที่หรือแก้ไขขั้นตอนการขออนุมัติโครงการ งบประมาณ หรือชั่วโมงกิจกรรมเดิมของมหาวิทยาลัย ตาม R39

- DOM-ACT-03 กิจกรรมที่นำเข้าสู่ระบบต้องผ่านการอนุมัติจากมหาวิทยาลัยเรียบร้อยแล้วก่อนสร้างกิจกรรมในระบบ

- IF-ACT-01 ระบบต้องรองรับการบันทึก URL อะไรก็ได้ที่ผู้จัดเตรียมไว้สำหรับการลงทะเบียนกิจกรรม

- IF-ACT-02 กิจกรรมสามารถมีวันเวลาสำหรับรอบเดียวหรือหลายรอบในวันเดียวกัน เช่น เช้า/บ่าย โดยไม่ต้องสร้างกิจกรรมแยกกัน


## Requirements

FR-ACT-01 ระบบต้องให้ผู้จัดกิจกรรมที่ได้รับสิทธิ์เปิดหน้า "สร้างกิจกรรมใหม่" ได้

FR-ACT-02 ระบบต้องให้ผู้จัดกิจกรรมกรอกรายละเอียดกิจกรรม ได้แก่ ชื่อ ประเภทกิจกรรม วันเวลาที่จัด สถานที่ที่จัด จำนวนรับสมัคร และชั่วโมงจิตอาสาที่จะได้รับ

FR-ACT-03 ระบบต้องให้ผู้จัดกิจกรรมแนบลิงก์ URL สำหรับใช้ลงทะเบียนกิจกรรมได้

FR-ACT-04 เมื่อผู้จัดกิจกรรมกรอกข้อมูลไม่ครบ ระบบต้องแจ้งช่องข้อมูลที่ยังต้องกรอก

FR-ACT-05 ระบบต้องบันทึกกิจกรรมเมื่อข้อมูลที่จำเป็นครบถ้วน

FR-ACT-06 เมื่อบันทึกกิจกรรมสำเร็จ ระบบต้องทำให้กิจกรรมนั้นปรากฏในรายการกิจกรรมที่นักศึกษาสามารถค้นหาได้

FR-ACT-07 ระบบต้องไม่เพิ่มขั้นตอนอนุมัติโครงการ งบประมาณ หรือชั่วโมงของมหาวิทยาลัยเข้ามาในกระบวนการสร้างกิจกรรม

FR-ACT-08 เมื่อผู้จัดกิจกรรมแก้ไขข้อมูลกิจกรรม ระบบต้องบันทึกประวัติการแก้ไข (edit log) ไว้ในระบบ

FR-ACT-09 เมื่อผู้จัดกิจกรรมยกเลิกกิจกรรม ระบบต้องแจ้งเตือนไปยังผู้ที่ลงทะเบียนว่ากิจกรรมถูกยกเลิกแล้ว


## Quality Requirements

- NFR-ACT-01 ระบบต้องรองรับผู้ใช้งานได้อย่างน้อย ~5,000 คนต่อภาคการศึกษา


## Acceptance Criteria

- [ ] AC-ACT-01

    Given ผู้จัดกิจกรรมได้รับสิทธิ์ใช้งานจาก Admin แล้ว
    And กิจกรรมผ่านการอนุมัติจากมหาวิทยาลัยแล้ว
    When ผู้จัดกิจกรรมเปิดหน้า "สร้างกิจกรรมใหม่"
    Then ระบบแสดงแบบฟอร์มสำหรับกรอกรายละเอียดกิจกรรม


- [ ] AC-ACT-02

    Given ผู้จัดกิจกรรมอยู่ในหน้าสร้างกิจกรรม
    When ผู้จัดกิจกรรมกรอกข้อมูลกิจกรรม
    Then ระบบสามารถรับข้อมูลชื่อ ประเภทกิจกรรม วันเวลาที่จัด สถานที่ที่จัด จำนวนรับสมัคร และชั่วโมงจิตอาสาที่จะได้รับได้


- [ ] AC-ACT-03

    Given ผู้จัดกิจกรรมกรอกรายละเอียดกิจกรรมแล้ว
    When ผู้จัดกิจกรรมเพิ่มลิงก์ URL สำหรับลงทะเบียนกิจกรรม
    Then ระบบสามารถบันทึกลิงก์ URL ไว้กับกิจกรรมนั้นได้


- [ ] AC-ACT-04

    Given ผู้จัดกิจกรรมยังกรอกข้อมูลที่จำเป็นไม่ครบ
    When ผู้จัดกิจกรรมกดบันทึก
    Then ระบบแจ้งช่องข้อมูลที่ยังต้องกรอกเพิ่ม


- [ ] AC-ACT-05

    Given ผู้จัดกิจกรรมกรอกข้อมูลที่จำเป็นครบถ้วน
    And กิจกรรมอยู่ใน 1 ใน 5 ประเภทที่มหาวิทยาลัยรับรอง
    When ผู้จัดกิจกรรมกดบันทึก
    Then ระบบบันทึกกิจกรรมเข้าสู่ระบบสำเร็จ


- [ ] AC-ACT-06

    Given ผู้จัดกิจกรรมบันทึกกิจกรรมสำเร็จ
    When นักศึกษาเปิดรายการกิจกรรม
    Then กิจกรรมที่สร้างใหม่ปรากฏในรายการที่นักศึกษาสามารถค้นหาได้


- [ ] AC-ACT-07

    Given กิจกรรมผ่านการอนุมัติจากมหาวิทยาลัยเรียบร้อยแล้ว
    When ผู้จัดกิจกรรมนำกิจกรรมเข้าสู่ระบบ
    Then ระบบไม่เริ่มกระบวนการขออนุมัติโครงการ งบประมาณ หรือชั่วโมงจากมหาวิทยาลัยใหม่


- [ ] AC-ACT-08

    Given ผู้จัดกิจกรรมสร้างกิจกรรมแล้ว
    When ผู้จัดกิจกรรมแก้ไขข้อมูลกิจกรรมใด ๆ
    Then ระบบบันทึกประวัติการแก้ไข (edit log) และแสดงให้เห็นได้ในประวัติกิจกรรม


- [ ] AC-ACT-09

    Given ผู้จัดกิจกรรมมีผู้ลงทะเบียนแล้ว
    And ผู้จัดกิจกรรมยกเลิกกิจกรรม
    When ระบบประมวลผลคำสั่งยกเลิก
    Then ระบบแจ้งเตือนไปยังผู้ที่ลงทะเบียนว่ากิจกรรมถูกยกเลิกแล้ว


## Assumptions & Open Questions

- ASM-ACT-01 กิจกรรมที่ผู้จัดนำเข้าสู่ระบบถือว่าผ่านกระบวนการอนุมัติของมหาวิทยาลัยเรียบร้อยแล้วก่อนเริ่ม UC-08

- ASM-ACT-02 ก่อนบันทึกกิจกรรมใหม่จริง ๆ ระบบจะแสดงหน้าตรวจสอบอีกครั้งเพื่อให้ผู้จัดยืนยันว่าต้องการสร้างกิจกรรมนี้จริง ๆ

- ASM-ACT-03 รายละเอียดกิจกรรมที่ต้องกรอกมีดังนี้: ชื่อ, ประเภทกิจกรรม, วันเวลาที่จัด, สถานที่ที่จัด, จำนวนรับสมัคร, และชั่วโมงจิตอาสาที่จะได้รับ

- ASM-ACT-04 ลิงก์ URL สำหรับลงทะเบียนกิจกรรมสามารถเป็น URL อะไรก็ได้ที่ผู้จัดเตรียมไว้ และไม่จำกัดให้เป็น URL ของ Google Form เท่านั้น

- ASM-ACT-05 กิจกรรมสามารถมีวันเวลาเดียวหรือหลายรอบในวันเดียวกัน เช่น เช้า/บ่าย โดยไม่ต้องสร้างกิจกรรมแยกกัน

- ASM-ACT-06 เมื่อผู้จัดแก้ไขกิจกรรม ระบบต้องบันทึกประวัติการแก้ไข (edit log) และเมื่อยกเลิกกิจกรรมแล้ว ระบบต้องแจ้งเตือนผู้ที่ลงทะเบียนว่ากิจกรรมถูกยกเลิก

No open questions remain after team clarification.
