# Feature : สร้างกิจกรรมใหม่ (Create Activity)


## Goal

ตัวแทนองค์การนักศึกษาที่ได้รับสิทธิ์จาก Admin และมีกิจกรรมที่ผ่านการอนุมัติจากมหาวิทยาลัยแล้ว
สามารถบันทึกรายละเอียดกิจกรรมและช่องทางลงทะเบียนเข้าสู่ระบบ
เพื่อให้นักศึกษาสามารถค้นหาและเห็นกิจกรรมนั้นได้


## Scope

### In Scope

- ผู้จัดกิจกรรมเปิดหน้า "สร้างกิจกรรมใหม่"
- กรอกรายละเอียดกิจกรรม ได้แก่ ชื่อ ประเภท วันเวลา สถานที่ จำนวนรับสมัคร และชั่วโมงที่ได้รับอนุมัติ
- แนบลิงก์ Google Form สำหรับใช้ลงทะเบียนกิจกรรม
- บันทึกกิจกรรมเข้าสู่ระบบ
- ตรวจสอบว่าข้อมูลที่จำเป็นถูกกรอกครบก่อนบันทึก
- เผยแพร่กิจกรรมให้นักศึกษาเห็นหลังบันทึกสำเร็จ
- กิจกรรมต้องอยู่ในประเภทกิจกรรมที่มหาวิทยาลัยรับรอง


### Out Scope

- การขออนุมัติโครงการจากมหาวิทยาลัย
- การขออนุมัติงบประมาณ
- การขออนุมัติจำนวนชั่วโมงจิตอาสา
- การจัดการสิทธิ์ผู้จัดกิจกรรม
- การลงทะเบียนเข้าร่วมกิจกรรมของนักศึกษา
- การแก้ไขหรือลบกิจกรรมหลังจากสร้างแล้ว
- การอนุมัติกิจกรรมซ้ำโดย Admin ก่อนเผยแพร่
  (ยังต้อง Clarify เนื่องจากขัดกับ User Story ID 1)


## Constraints

- CON-ACT-01 ผู้จัดกิจกรรมต้องได้รับสิทธิ์ใช้งานจาก Admin แล้วก่อนสร้างกิจกรรม ตาม UC-08 Precondition

- DOM-ACT-01 กิจกรรมที่สร้างต้องเป็น 1 ใน 5 ประเภทที่มหาวิทยาลัยรับรอง ได้แก่ วิชาการ, กีฬา, ศิลปวัฒนธรรม, คุณธรรมจริยธรรม และบำเพ็ญประโยชน์

- DOM-ACT-02 ระบบต้องไม่เข้าไปแทนที่หรือแก้ไขขั้นตอนการขออนุมัติโครงการ งบประมาณ หรือชั่วโมงกิจกรรมเดิมของมหาวิทยาลัย ตาม R39

- DOM-ACT-03 กิจกรรมที่นำเข้าสู่ระบบต้องผ่านการอนุมัติจากมหาวิทยาลัยเรียบร้อยแล้วก่อนสร้างกิจกรรมในระบบ

- IF-ACT-01 ระบบต้องรองรับการบันทึกลิงก์ Google Form ที่ผู้จัดเตรียมไว้สำหรับการลงทะเบียนกิจกรรม


## Requirements

FR-ACT-01 ระบบต้องให้ผู้จัดกิจกรรมที่ได้รับสิทธิ์เปิดหน้า "สร้างกิจกรรมใหม่" ได้

FR-ACT-02 ระบบต้องให้ผู้จัดกิจกรรมกรอกรายละเอียดกิจกรรม ได้แก่ ชื่อ ประเภท วันเวลา สถานที่ จำนวนรับสมัคร และชั่วโมงที่ได้รับอนุมัติ

FR-ACT-03 ระบบต้องให้ผู้จัดกิจกรรมแนบลิงก์ Google Form สำหรับใช้ลงทะเบียนกิจกรรมได้

FR-ACT-04 เมื่อผู้จัดกิจกรรมกรอกข้อมูลไม่ครบ ระบบต้องแจ้งช่องข้อมูลที่ยังต้องกรอก

FR-ACT-05 ระบบต้องบันทึกกิจกรรมเมื่อข้อมูลที่จำเป็นครบถ้วน

FR-ACT-06 เมื่อบันทึกกิจกรรมสำเร็จ ระบบต้องทำให้กิจกรรมนั้นปรากฏในรายการกิจกรรมที่นักศึกษาสามารถค้นหาได้

FR-ACT-07 ระบบต้องไม่เพิ่มขั้นตอนอนุมัติโครงการ งบประมาณ หรือชั่วโมงของมหาวิทยาลัยเข้ามาในกระบวนการสร้างกิจกรรม


## Quality Requirements

- NFR-ACT-01 ระบบต้องรองรับผู้ใช้งานได้อย่างน้อย ~5,000 คนต่อภาคการศึกษา


## Acceptance Criteria

- [ ] AC-ACT-01

    Given ผู้จัดกิจกรรมได้รับสิทธิ์ใช้งานจาก Admin แล้ว
    And กิจกรรมผ่านการอนุมัติจากมหาวิทยาลัยแล้ว
    When ผู้จัดกิจกรรมเปิดหน้า "สร้างกิจกรรมใหม่"
    Then ระบบแสดงแบบฟอร์มสำหรับกรอกรายละเอียดกิจกรรม


- [ ] AC-ACT-02

    Given ผู้จัดกิจกรรมอยู่ในหน้าสร้างกิจกรรม
    When ผู้จัดกิจกรรมกรอกข้อมูลกิจกรรม
    Then ระบบสามารถรับข้อมูลชื่อ ประเภท วันเวลา สถานที่ จำนวนรับสมัคร และชั่วโมงที่ได้รับอนุมัติได้


- [ ] AC-ACT-03

    Given ผู้จัดกิจกรรมกรอกรายละเอียดกิจกรรมแล้ว
    When ผู้จัดกิจกรรมเพิ่มลิงก์ Google Form
    Then ระบบสามารถบันทึกลิงก์ Google Form ไว้กับกิจกรรมนั้นได้


- [ ] AC-ACT-04

    Given ผู้จัดกิจกรรมยังกรอกข้อมูลที่จำเป็นไม่ครบ
    When ผู้จัดกิจกรรมกดบันทึก
    Then ระบบแจ้งช่องข้อมูลที่ยังต้องกรอกเพิ่ม


- [ ] AC-ACT-05

    Given ผู้จัดกิจกรรมกรอกข้อมูลที่จำเป็นครบถ้วน
    And กิจกรรมอยู่ใน 1 ใน 5 ประเภทที่มหาวิทยาลัยรับรอง
    When ผู้จัดกิจกรรมกดบันทึก
    Then ระบบบันทึกกิจกรรมเข้าสู่ระบบสำเร็จ


- [ ] AC-ACT-06

    Given ผู้จัดกิจกรรมบันทึกกิจกรรมสำเร็จ
    When นักศึกษาเปิดรายการกิจกรรม
    Then กิจกรรมที่สร้างใหม่ปรากฏในรายการที่นักศึกษาสามารถค้นหาได้


- [ ] AC-ACT-07

    Given กิจกรรมผ่านการอนุมัติจากมหาวิทยาลัยเรียบร้อยแล้ว
    When ผู้จัดกิจกรรมนำกิจกรรมเข้าสู่ระบบ
    Then ระบบไม่เริ่มกระบวนการขออนุมัติโครงการ งบประมาณ หรือชั่วโมงจากมหาวิทยาลัยใหม่


## Assumptions & Open Questions

- ASM-ACT-01 กิจกรรมที่ผู้จัดนำเข้าสู่ระบบถือว่าผ่านกระบวนการอนุมัติของมหาวิทยาลัยเรียบร้อยแล้วก่อนเริ่ม UC-08

- Q-ACT-01 UC-08 ระบุว่ากิจกรรมเผยแพร่ให้นักศึกษาเห็นทันทีและไม่มีขั้นตอนรอ Admin อนุมัติซ้ำ แต่ User Story ID 1 ระบุว่า Admin ต้องตรวจสอบและอนุมัติกิจกรรมก่อนเผยแพร่ — ต้องยืนยันว่ากระบวนการใดเป็น Requirement ล่าสุด

- Q-ACT-02 UC-08 ระบุว่าสามารถแนบ Google Form ที่เตรียมไว้ "หรือให้ระบบช่วยสร้างจาก template" — ต้องยืนยันว่าการสร้าง Google Form จาก template อยู่ใน Scope ของ feature นี้หรือเป็น feature แยก

- Q-ACT-03 ยังไม่ระบุว่าช่องข้อมูลใดเป็น Required Field นอกเหนือจากรายการที่ปรากฏใน UC-08

- Q-ACT-04 ยังไม่ระบุรูปแบบและ Validation ของลิงก์ Google Form เช่น ต้องเป็น URL ของ Google Forms เท่านั้นหรือสามารถใช้ URL อื่นได้

- Q-ACT-05 ยังไม่ระบุว่าวันเวลา 1 กิจกรรมรองรับช่วงเวลาเดียวหรือหลายช่วงเวลา

- Q-ACT-06 ยังไม่ระบุว่าหลังจากสร้างกิจกรรมแล้ว ผู้จัดสามารถแก้ไขหรือลบกิจกรรมได้หรือไม่

- Q-ACT-07 R11 ระบุรายละเอียดกิจกรรมที่ต้องส่งเข้าสู่ระบบ แต่ไม่ได้กล่าวถึง Google Form ขณะที่ UC-08 ระบุให้ผูก Google Form — ต้องยืนยันว่า Google Form เป็น Requirement บังคับหรือเป็นทางเลือก

- Q-ACT-08 NFR ระบุว่าระบบต้องรองรับผู้ใช้ ~5,000 คนต่อภาคการศึกษา แต่ยังไม่ระบุจำนวนผู้ใช้พร้อมกันหรือเกณฑ์ response time สำหรับการสร้างกิจกรรม
