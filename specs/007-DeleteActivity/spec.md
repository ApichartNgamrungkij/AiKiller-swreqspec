
# Feature : ลบ/ระงับกิจกรรม (DeleteActivity)

Status: Draft v2
Updated: 2026-10-04

# Goal
Admin สามารถลบหรือระงับการแสดงผลกิจกรรมที่ไม่เหมาะสมหรือผิดเงื่อนไขภายหลังจากที่เผยแพร่แล้ว เพื่อไม่ให้กิจกรรมดังกล่าวปรากฏในรายการกิจกรรมของนักศึกษา และสามารถตรวจสอบการดำเนินการย้อนหลังได้

---
## Scope

### In Scope
Admin สามารถดูรายการกิจกรรมที่เผยแพร่แล้ว
Admin สามารถดูข้อมูลกิจกรรมที่ถูกลบหรือระงับได้เพื่อการตรวจสอบย้อนหลัง
Admin สามารถเลือกกิจกรรมที่ต้องการลบหรือระงับได้
Admin ต้องระบุเหตุผลในการลบหรือระงับกิจกรรม
ระบบต้องซ่อนกิจกรรมที่ถูกลบหรือระงับจากนักศึกษา
ระบบต้องบันทึกการลบ/ระงับกิจกรรมลง Audit Log

### Out Scope
การสร้างกิจกรรมใหม่
การแก้ไขรายละเอียดกิจกรรม
การอนุมัติกิจกรรม
การลงทะเบียนกิจกรรม
การจัดการข้อมูลการลงทะเบียนของนักศึกษา

## Constraints
IF-ADMIN-01 Admin ต้องเข้าสู่ระบบและมีสิทธิ์ Admin ก่อนจึงจะสามารถลบหรือระงับกิจกรรมได้
IF-DEL-01 ต้องมีกิจกรรมที่เผยแพร่อยู่ในระบบก่อนจึงจะสามารถลบหรือระงับได้
IF-REASON-01 Admin ต้องระบุเหตุผลก่อนยืนยันการลบหรือระงับกิจกรรม
IF-HIDE-01 กิจกรรมที่ถูกลบหรือระงับต้องไม่ปรากฏในรายการกิจกรรมที่นักศึกษาเห็น แต่ยังคงมีข้อมูลเพื่อให้ Admin ตรวจสอบย้อนหลังได้
ACC-AUDIT-01 การลบหรือระงับกิจกรรมต้องถูกบันทึกลง Audit Log เพื่อตรวจสอบย้อนหลังได้ โดยมีข้อมูลผู้ทำ เวลา เหตุผล และประเภทการดำเนินการ
ACC-ADMIN-01 ผู้ใช้งานที่ไม่มีสิทธิ์ Admin ต้องไม่สามารถลบหรือระงับกิจกรรมได้
CON-DEL-01 การลบหรือระงับกิจกรรมหนึ่งต้องไม่กระทบกิจกรรมอื่น

##Requirements
      FR-DEL-01 ระบบต้องให้ Admin เลือกกิจกรรมที่ต้องการลบหรือระงับได้
   FR-DEL-02 ระบบต้องให้ Admin เลือกการดำเนินการ "ลบ" หรือ "ระงับ" กิจกรรม
   FR-DEL-03 ระบบต้องให้ Admin ระบุเหตุผลก่อนยืนยันการลบหรือระงับกิจกรรม
      FR-DEL-04 ระบบต้องให้ Admin ยืนยันการลบหรือระงับกิจกรรมก่อนดำเนินการ
      FR-DEL-05 ระบบต้องซ่อนกิจกรรมที่ถูกลบหรือระงับจากรายการกิจกรรมที่นักศึกษาเห็น
      FR-DEL-06 ระบบต้องบันทึกข้อมูลการลบหรือระงับกิจกรรมลง Audit Log
      FR-DEL-07 ระบบต้องป้องกันผู้ใช้งานที่ไม่มีสิทธิ์ Admin ไม่ให้สามารถลบหรือระงับกิจกรรมได้

## Quality Requirements
NFR-DEL-01 ระบบต้องตรวจสอบสิทธิ์ของผู้ใช้งานก่อนดำเนินการลบหรือระงับกิจกรรม
NFR-DEL-02 ระบบต้องส่งข้อมูลระหว่างผู้ใช้กับเซิร์ฟเวอร์ผ่าน HTTPS
NFR-DEL-03 ระบบต้องมี Audit Log สำหรับตรวจสอบการลบหรือระงับกิจกรรมย้อนหลัง

## Acceptance Criteria
- [] AC-DEL-01
Given มีกิจกรรมที่เผยแพร่อยู่ในระบบ และผู้ใช้งานเป็น Admin
When Admin เปิดรายการกิจกรรม
Then ระบบต้องให้ Admin เลือกกิจกรรมที่ต้องการลบหรือระงับได้
- [] AC-DEL-02
Given Admin เลือกกิจกรรมที่ต้องการจัดการ
When Admin เลือกลบหรือระงับกิจกรรม
Then ระบบต้องให้ Admin ระบุเหตุผลและยืนยันการดำเนินการ
- [] AC-DEL-03
Given Admin ยังไม่ได้ระบุเหตุผล
When Admin พยายามยืนยันการลบหรือระงับ
Then ระบบต้องไม่ดำเนินการและแจ้งให้ระบุเหตุผล
- [] AC-DEL-04
Given Admin ยืนยันการลบหรือระงับกิจกรรมสำเร็จ
When นักศึกษาเปิดรายการกิจกรรม
Then กิจกรรมดังกล่าวต้องไม่ปรากฏในรายการของนักศึกษา
- [] AC-DEL-05
Given Admin ยืนยันการลบหรือระงับกิจกรรมสำเร็จ
When ระบบบันทึกผลการดำเนินการ
Then ระบบต้องบันทึกการดำเนินการลง Audit Log
- [] AC-DEL-06
Given ผู้ใช้งานไม่มีสิทธิ์ Admin
When พยายามลบหรือระงับกิจกรรม
Then ระบบต้องปฏิเสธการดำเนินการ

## Assumptions & Open Questions
ASM-01 ผู้ที่ดำเนินการลบหรือระงับกิจกรรมต้องเป็น Admin ที่เข้าสู่ระบบแล้ว
ASM-02 การลบหรือระงับกิจกรรมหมายถึงการไม่แสดงกิจกรรมนั้นให้นักศึกษาเห็น
ASM-03 การลบและระงับกิจกรรมเป็นรูปแบบ Soft Delete/เปลี่ยนสถานะเดียวกัน โดยไม่ลบข้อมูลจริงออกจากระบบ
ASM-04 กิจกรรมที่ถูกระงับจะไม่ถูกแสดงให้นักศึกษาเห็น แต่ Admin ยังสามารถดูเพื่อตรวจสอบย้อนหลังได้
ASM-05 Audit Log ต้องบันทึกข้อมูลผู้ทำ เวลา เหตุผล และประเภทการดำเนินการ (ลบ/ระงับ)
