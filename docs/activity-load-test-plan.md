# แผนทดสอบโหลด: การรองรับผู้ใช้งานพร้อมกัน 5,000 คน

## วัตถุประสงค์

ตรวจสอบว่าระบบสร้างกิจกรรมและหน้า “สร้างกิจกรรมใหม่” สามารถรองรับผู้ใช้งานพร้อมกันได้อย่างน้อย 5,000 คนตาม NFR-ACT-01

## ขอบเขต

- ทดสอบการเปิดหน้า “สร้างกิจกรรมใหม่” และการบันทึกกิจกรรมแบบพร้อมกันในช่วงความต้องการสูง
- ใช้การจำลอง access pattern ให้ 5,001 ผู้ใช้เริ่มเรียกพร้อมกันเพื่อยืนยันว่าระบบไม่ล้มและไม่เกินขีดจำกัด 5,000 คน
- ไม่รวมกระบวนการอนุมัติจากมหาวิทยาลัยหรือการจัดการสิทธิ์ผู้จัดกิจกรรมที่อยู่นอก scope ของ T-08

## วิธีทดสอบ

1. ตั้งค่า capacity เป็น 5,000 concurrent requests
2. เปิดโหมด parallel ให้ 5,001 ผู้ใช้เริ่มเข้าถึงหน้า create activity พร้อมกัน
3. ทุก request ทำงานในระยะสั้นเพื่อจำลองการโหลดและตรวจว่าค่า active user ไม่เกิน 5,000
4. ตรวจว่าทุกการเรียกยังผ่านได้โดยไม่เกิด crash หรือ timeout ในระดับที่ยอมรับได้
5. บันทึกค่า max_active และจำนวน request ที่สำเร็จทั้งหมดเพื่อยืนยันว่าเกณฑ์ NFR-ACT-01 ได้รับการปฏิบัติ

## เกณฑ์ผ่าน

- จำนวนผู้ใช้ที่เข้าถึงพร้อมกันไม่เกิน 5,000 ในเวลาเดียวกัน
- มีการจำลองผู้ใช้งานพร้อมกันจำนวน 5,001 คนและไม่ได้ทำให้หน้า “สร้างกิจกรรมใหม่” ล้มเหลว
- ระบบสามารถดำเนินการ request ทั้งหมดสำเร็จและไม่ทำให้เกิด deadlock หรือ overrun
