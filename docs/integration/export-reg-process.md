# ExportList และกระบวนการ REG เดิม

เอกสารนี้เป็น integration contract ของฟีเจอร์ ExportList ตาม
`specs/006-ExportList/spec.md` โดยยืนยันว่าการส่งออกรายชื่อไม่สร้าง workflow
REG ใหม่และไม่เปลี่ยนขั้นตอนอนุมัติโครงการเดิม

## การดำเนินการต่อใน REG

1. ผู้จัดกิจกรรมเปิด Google Sheets ของกิจกรรมผ่านระบบเมื่อผ่านการตรวจสิทธิ์
2. ผู้จัดกิจกรรมเลือกดาวน์โหลดหรือบันทึกข้อมูลเป็น `.xlsx` หรือ `.csv`
3. ผู้จัดกิจกรรมนำไฟล์ไปดำเนินการต่อในระบบ REG ด้วยตนเองตามกระบวนการเดิมของมหาวิทยาลัย

ระบบกิจกรรมไม่อัปโหลดไฟล์หรือส่งรายชื่อไปยัง REG โดยอัตโนมัติ ข้อมูลใน Google
Sheets ไม่ถูกแก้ไขหรือตัดคอลัมน์ระหว่างขั้นตอน ExportList

## ขอบเขตการอนุมัติโครงการ

การขออนุมัติโครงการของมหาวิทยาลัยยังคงเป็นความรับผิดชอบของกระบวนการเดิม
ExportList ไม่มี endpoint, state หรือการเปลี่ยนแปลงใด ๆ ที่แทนที่หรือแก้ไข
ขั้นตอนดังกล่าว

## Traceability

| ข้อกำหนด | การรองรับ |
|---|---|
| `FR-EXP-05`, `IF-REG-01` | ผู้จัดกิจกรรมเป็นผู้ดำเนินการต่อใน REG เอง |
| `FR-EXP-06` | ไม่มีการอัปโหลดหรือส่งข้อมูลเข้า REG อัตโนมัติ |
| `FR-EXP-07`, `DOM-APP-01` | ไม่สร้างหรือเปลี่ยนขั้นตอนอนุมัติโครงการ |
| `ASM-04`, `ASM-07` | พึ่งพากระบวนการ REG และการอนุมัติเดิมของมหาวิทยาลัย |
